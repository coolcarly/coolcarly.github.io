There is not a lot of difference between the different breads that we consume (in terms of ingredients). A basic bread, including pizza doughs, foccacias or any other bread type (excluding banana bread) is made mostly of flour and water. 

|Bread|Pizza dough|Pastry|Pasta|
|---|---|---|---|
|Flour <br/> Water <br/> Salt <br/> Yeast |Flour <br/> Water (sometimes milk) <br/> Salt <br/> Yeast <br/> Oil| Flour <br/> Oil and/or butter <br/> Salt <br/> Water| Flour <br/> Oil <br/> Salt <br/> Eggs |
